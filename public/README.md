# public/

Drop static assets here:

- `resume.pdf` — your latest resume (rendered from the LaTeX source)
- `headshot.jpg` or `headshot.png` — profile photo for the hero (square, ~600x600)
- `projects/` — screenshots/diagrams for each featured project
- `favicon.ico` — generated later in the SEO step
- `og-image.png` — Open Graph preview image, generated later
